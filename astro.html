Necesita conexión a internet. Cada cálculo descarga la previsión de Open‑Meteo (api.open-meteo.com) y la transparencia atmosférica del modelo CAMS (air-quality-api.open-meteo.com). Sin red la página se abre igual, pero no puede predecir nada. No hay clave ni registro; tus observaciones se quedan en este navegador.

An internet connection is required. Every computation downloads the forecast from Open‑Meteo (api.open-meteo.com) and the atmospheric transparency from the CAMS model (air-quality-api.open-meteo.com). With no network the page still opens, but it cannot forecast anything. There is no API key and no sign‑up; your observations stay in this browser.
